# FashionFinder
An AI-powered Fashion Recommender System that recommends visually similar fashion items based on an uploaded image. The system uses MobileNetV2 to extract image features and K-Nearest Neighbors (KNN) to find the most similar fashion products.

🚀 Features

Upload a fashion/product image

Extract visual features using MobileNetV2

Find visually similar fashion items using KNN

Display the Top 5 similar products

Simple and interactive Streamlit interface

🧠 How It Works

The recommendation process follows these steps:

User uploads image
        ↓
Image preprocessing
        ↓
MobileNetV2
        ↓
Feature Extraction
        ↓
Feature Vector
        ↓
KNN Similarity Search
        ↓
Top 5 Similar Fashion Items
        ↓
Display Recommendations
